# AssetManager (AES-256 보안 자산 관리자)

PowerShell 기반의 Zero-Knowledge(영지식) AES-256 군사 표준 암호화 로컬 자산/계정 관리 도구입니다.

## 🚀 주요 보안 및 기능
- **🛡️ AES-256 + PBKDF2 Zero-Knowledge 완전 암호화**:
  - 사용자 마스터 비밀번호로 `PBKDF2`(SHA-256, 50,000회 반복 연산)를 거쳐 256비트 암호화 키를 실시간 유도.
  - 파일 안이나 코드 내에 복호화 키가 전혀 존재하지 않으며, 비밀번호가 유일한 열쇠입니다.
  - Windows AD 도메인 정책(비밀번호 주기적 변경)이나 PC 변경/포맷에 영향을 받지 않는 독립 암호화 엔진.
  - 비밀번호를 모르면 전 세계 누구도 역공학이나 바이너리 분석으로 데이터 복구 불가.
- **🔐 실행 시 인증 및 세션 제어**:
  - 콘솔 내 비밀번호 입력 시 `*` 마스킹 지원.
  - 복호화 5회 연속 실패 시 자동 강제 종료.
- **자산 관리 풀 세트**:
  - 자산 검색 (IP/URL 모드 & 텍스트 키워드 모드 자동 전환)
  - 전체 자산 조회 (한글/영문 너비 맞춤 콘솔 테이블)
  - 자산 등록 / 수정 / 삭제 (IP 중복 방지 기능 탑재)
  - 마스터 비밀번호 변경 (데이터 전체 즉시 재암호화)

## 📁 파일 구성
- `AssetManager.ps1`: AES-256 암호화 및 자산 관리 메인 스크립트
- `자산관리실행.bat`: 원클릭 실행 배치 파일
- `.gitignore`: 암호화된 자산 데이터(`SecureAssets.dat`) 등 개인정보 보호

## 💻 실행 방법
1. `자산관리실행.bat`을 더블 클릭하여 실행하거나
2. PowerShell에서 실행:
```powershell
powershell -ExecutionPolicy Bypass -File .\AssetManager.ps1
```
